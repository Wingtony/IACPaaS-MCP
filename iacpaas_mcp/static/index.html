База знаний

Информационные ресурсы, доступные вашему агенту.

Атлас ваших знаний

Агент исследует графовую базу IACPaaS с помощью выбранной локальной или облачной модели.

Диалоги сохраняются на этом ПК. Локальная модель остаётся в памяти до остановки приложения. В облачном режиме вопрос, история и каталог понятий передаются выбранному провайдеру. Каждое изменение данных требует отдельного подтверждения.

Подключение IACPaaS

Данные входа хранятся на этом ПК, зашифрованные для вашей учётной записи Windows.

Пустой пароль сохраняет прежний только для того же логина. При сохранении проверяется вход; менять пароль на самой платформе эта форма не будет. Запись в базы выключена.

Модели и API

Выберите локальную Qwen или подключите облачную модель. Ответы по базе проходят ту же проверку MCP.

Можно выбрать пример или ввести точный ID модели из вашего аккаунта.

В облако передаются вопрос, сжатая история (включая предыдущие ответы) и каталог понятий базы. API оплачивается по тарифу провайдера. Ключ хранится на этом ПК через Windows DPAPI и не возвращается браузеру.

Проверка выполняет короткий платный API-запрос без данных базы. Доступность не проверяется автоматически при сохранении.
