# Локальная и облачные модели

В боковой панели нажмите **Модели и API**. Выберите провайдера, API ID модели и введите свой ключ. Нажмите **Сохранить выбор**, затем при необходимости **Проверить сохранённую модель**. Проверка выполняет короткий оплачиваемый запрос без истории или данных IACPaaS. Без ключа запрос не отправляется. Наличие сохранённого ключа не означает, что доступ к API уже проверен.

| Провайдер | API | Примеры API ID в интерфейсе |
|---|---|---|
| Ollama | локальный `/api/chat` | `qwen-agent` |
| OpenAI | Responses API `/v1/responses`, JSON Schema | `gpt-4.1-mini`, `gpt-4.1` |
| Anthropic | Messages API `/v1/messages`, `output_config.format` | `claude-haiku-4-5`, `claude-sonnet-4-5` |
| Google Gemini | OpenAI compatibility `/v1beta/openai/chat/completions` | `gemini-3.8-flash`, `gemini-2.5-flash` |
| DeepSeek | `/chat/completions`, JSON mode | `deepseek-flash` |
| OpenRouter | `/api/v1/chat/completions`, JSON mode | `openai/gpt-4.1-mini`, `anthropic/claude-haiku-4.5` |

Примеры — стартовый список, не обещание доступности каждому аккаунту и не рекомендация по цене. Можно ввести другой точный API ID. У выбранной модели должны поддерживаться текстовые запросы и используемый провайдером формат JSON. Доступ, регион, баланс и лимиты определяет провайдер. На собственные API-адреса ключи отправлять нельзя: endpoints фиксированы в коде, перенаправления отключены.

## Работа с данными и ключами

В облако передаются системная инструкция, схема плана, вопрос, доступная сжатая история (в том числе прошлые ответы с данными) и каталог классов/элементов/свойств из подключённых баз. Пароль и токен IACPaaS в запрос модели не включаются. Полные снимки графов не добавляются автоматически в облачный запрос. Возвращённый план проверяется Pydantic и семантическими правилами; получение данных, вычисления и повторная сверка ответа по снимкам остаются в MCP. Ограничения основного планировщика из `spec-audit.md` сохраняются.

Ключи разных провайдеров и выбранная модель сохраняются на сервере в `.local/llm.dpapi`, зашифрованном Windows DPAPI для текущей учётной записи. Это отдельный файл от аккаунта IACPaaS. Браузеру возвращаются только признаки наличия ключа и его источника, без полного или частичного значения. Пустое поле сохраняет прежний ключ именно выбранного провайдера. Флажок удаления удаляет его сохранённую копию. При закрытии окна поле ключа очищается. Ключи не включаются в SQLite-диалоги, трассы и Git.

Можно задать ключ через переменную окружения: `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GEMINI_API_KEY`, `DEEPSEEK_API_KEY`, `OPENROUTER_API_KEY`. Она имеет приоритет над сохранённым ключом. Удаление копии в UI не удаляет переменную окружения — её нужно убрать отдельно. `LLM_PROVIDER` задаёт первоначальный провайдер; последующий выбор UI имеет приоритет. Сохранение через UI требует Windows; на других ОС можно использовать переменные окружения и CLI.

## Память и переключение

Выбор меняется между запросами, очередь блокирует смену настроек. Для каждого запроса фиксируются провайдер, модель и ключ, поэтому переключение не подменяет модель уже поставленного в очередь запроса. Ответ хранит название фактически использованной модели.

При штатном управляемом запуске переход с локальной модели на облачную освобождает память предыдущей модели Ollama. Новые облачные запросы не загружают и не выгружают Qwen. Запуск приложения с выбранным облаком не требует Ollama. Для возврата к локальной модели выберите Ollama и запустите её через окно управления. Локальная модель сохраняется между вопросами до остановки приложения, как и раньше.

Текущий входной бюджет и сжатие истории общие для всех провайдеров: окно приложения 32768, бюджет около 24000, выход до 2048 токенов по умолчанию. Это ограничение приложения, а не объявление реального контекстного окна любой выбранной облачной модели. Оценка входа приблизительная. Если произвольная модель имеет меньший лимит, уменьшите настройки контекста. Отмена прерывает ожидание приложения, но возврат уже списанной платы или остановка обработки у провайдера не гарантируются.

CLI с ключом из окружения или сохранённого хранилища:

```powershell
.\.venv\Scripts\python.exe -m iacpaas_mcp.agent --provider openai --model gpt-4.1-mini "Сколько материалов содержат Cr?"
```

Параметры CLI действуют для этого вызова и не меняют выбор сайта. Подключение через stdio и `--mcp-url` использует те же облачные адаптеры. Альтернативный `raw`-цикл облачные модели не поддерживает.

## Проверки

Автоматические тесты используют HTTP-заглушки: проверяют endpoints, заголовки, schema/JSON mode, счётчики токенов, безопасные ошибки 301/400/401/403/404/429/500, отказ и усечённый ответ, изоляцию ключей, CSRF, отсутствие Ollama-запросов в облачном режиме и полный путь через MCP с повторной верификацией для пяти провайдеров.

Итоговый локальный прогон: 139 тестов пройдены; `node --check iacpaas_mcp/static/app.js` и `git diff --check` без ошибок. В GitHub Actions добавлен отдельный Windows/Python 3.11 прогон без API-ключей.

UI проверен в изолированном localhost-приложении с учебной базой: открытие настроек, переключение на OpenAI, сохранение выбора через DPAPI, диагностика отсутствующего ключа. Реальные облачные генерации не выполнялись: ключи провайдеров на момент разработки не предоставлены. Реальную доступность следует проверять кнопкой после ввода собственного ключа.

Официальные источники, сверенные при реализации 22.10.2026: [OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs), [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini), [Claude Structured Outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs), [Gemini compatibility](https://ai.google.dev/gemini-api/docs/openai), [DeepSeek JSON mode](https://api-docs.deepseek.com/guides/json_mode/), [OpenRouter API](https://openrouter.ai/docs/api/reference/overview).
