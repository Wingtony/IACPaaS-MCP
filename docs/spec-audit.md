## Границы доказательств

- list_inforesources показывает подключённые пути из конфигурации, а не весь фонд аккаунта автоматически. Полный поиск означает все подключённые ресурсы; бинарные вложения не индексируются.
- Проверка JSON базовая, без доказательства соответствия онтологии. ТЗ называет проверку JSON/структуры, не полный онтологический валидатор. Названия предложенных tools иллюстративны. Описание universal/meta/simple не требует поддержки всех трёх форматов.
- SHA-256 и повторный расчёт подтверждают целостность и воспроизводимость по снимку. Они не гарантируют понимание вопроса, достаточность поиска или истинность самой базы на 100%.
- Предметные операции конечны: несколько независимых числовых условий и произвольные межресурсные соединения не представлены универсальным языком. Модель может выбрать низкоуровневые инструменты либо уточнить вопрос.
- Без облачных ключей реальные платные генерации не выполнялись. Контрактные тесты используют заглушки.
- Свободный итог VS Code формирует IDE-хост, а не Python-верификатор. В демонстрации числа и фактические пути вызовов верны, но в текстовом пересказе списка ресурсов встречалась опечатка. Источником истины остаётся результат MCP.
