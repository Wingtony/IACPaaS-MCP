## Длинный ввод и память

При окне 32K фактически обработано **23705 входных токенов**, 28 выходных. План сохранил нужную марку. Полное время холодного запроса: 43.05 с; обработка входа: 22.43 с. Заполнение всех 32768 токенов не проверялось.
Максимум по выборочным замерам: GPU 13942 МиБ (13.62 ГиБ), RAM всей системы 24.18 ГиБ. Это замеры раз в 2 секунды, а не гарантированные мгновенные пики.

Ранее автоматическое распределение GPU давало до 15600 МиБ и ошибки CUDA при повторной загрузке. На профиле 44 слоя последний общий прогон прошёл без повторов загрузчика; максимум VRAM в нём был 13995 МиБ. Есть ограниченная одна попытка восстановления после HTTP 500 без изменения вопроса/контекста. Причина внутри CUDA/Ollama не объявляется доказанно устранённой навсегда.

Тест диалога: 160 реплик, 132 сохранены полными, остальные заменены краткой памятью; ссылка «этого сплава» правильно разрешилась в 12Х18Н10Т. Этот тест повторял один предметный диалог; он не доказывает качество 160 разных вопросов.

## Что исправлено по ошибкам

- Al/алюминий разрешается в существующий класс «Сплавы на основе алюминия»; в текущем снимке 186 марок.
- «Сколько материалов содержат Cr?» — подсчёт присутствия компонента: 994, без подмены рейтингом.
- «Где больше хрома?» — рейтинг по верхней допустимой границе с явной подписью допущения.
- «Не менее 9%» проверяется по словам вопроса и не может молча превратиться в «не более 9%».
- Повтор класса в поле subject не становится фильтром по имени марки.
- Проверены И/ИЛИ при подсчёте материалов с несколькими указанными компонентами.

Сырые отчёты — локальные logs/benchmark-*.json. Первые ошибки сохранены в benchmark-live.json и benchmark-stress.json; финальные — в файлах с суффиксами final, bronze-fixed и release. Для текущей базы ожидаемые значения описаны в docs/test-questions.md.

## Общий запуск и остановка

Проверен реальный запуск через lifecycle.start, два запроса через HTTP веб-агента и присутствие Qwen в /api/ps после каждого ответа. Al дал 186 марок (19.52 с с первоначальной загрузкой каталога), Cr — 994 материала (5.36 с). Общая остановка через защищённый endpoint прекратила HTTP-сервер и освободила модель; это независимо подтверждено отсутствием соединения с Web и отсутствием Qwen в /api/ps. Запуск затем повторён из видимого окна управления. Сырые результаты — logs/lifecycle-check.json.
