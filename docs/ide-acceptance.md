# Демонстрация VS Code и standalone · 23.10.2026

Учётная запись подключена к реальной IACPaaS, не mock. Доверие папке, вход в GitHub/Copilot и подтверждения результатов выполнял пользователь. Автоматический контроль не менял разрешения IDE.

Локальные текстовые протоколы итогов: `logs/ide-acceptance/01-count.txt`, `02-metadata.txt`, `03-subgraph.txt`. Они содержат результаты аккаунта и исключены из Git. В репозитории остаётся этот обезличенный отчёт.

## Тот же сценарий standalone

```powershell
.\.venv\Scripts\python.exe -m iacpaas_mcp.agent --provider ollama --mode adaptive --max-steps 8 "Найди ресурс «Справочник по материалам» и посчитай в нём вершины и дуги."
```

Живой прогон `logs/agent-d1218c2282.jsonl`: модель выбрала list_inforesources → count_graph → finish. Результат **93593 / 93592 / 0**, совпадает с IDE. Python-хост повторно сверил подсчёт с сохранённым экспортом, а итог отобразил код. Использованы те же MCP-схемы и backend. Трасса и снимки остаются локальными.

Предыдущий неудачный прогон (`logs/agent-2f4766e47b.jsonl`) обнаружил истёкший JWT: платформа возвращала HTTP 200 с ошибкой авторизации. Обобщённая ошибка привела модель к неверному уточнению пути. Исправлены распознавание авторизации, обновление сохранённого токена того же аккаунта и диагностика; успешный прогон выполнен после исправления. Это отдельная реальная причина ошибки, помимо ограничений прежнего фиксированного планировщика.

## Дополнительный прогон Web

На обновлённом `http://127.0.0.1:8770` выполнен вопрос «Сколько материалов содержат Cr?». Локальная Qwen выбрала `query_knowledge` с `operation=materials`, `element=Cr`, затем `finish` с полученным ID источника. Результат: **994** материала, показаны первые 10; приложение повторно проверило вычисление, статус `verified_result`. Время 22,9 с; контекст 32768, входной бюджет 24000, выход 2048, оценка входа 8116 → 10372 между шагами. Сжатие не требовалось. Это оценка приложения, не точный токенизатор. Трасса `logs/web-2ad0f57767ed41f782b9d1ab3ce17c14.jsonl`.

Вопрос больше не подменяется рейтингом и не вызывает просьбу выбрать верхнюю/нижнюю границу. Подсчёт означает наличие компонента в описании состава: значение «не более» не доказывает ненулевую концентрацию в конкретной партии; это оговорено в самом ответе.

Второй исходно ошибочный вопрос «Сколько марок Al в базе? Покажи первые 10» проверен отдельным диалогом: **186** материалов класса «Сплавы на основе алюминия», первые 10 показаны, `verified_result`, 28,9 с. Модель выбрала `query_knowledge`; нулевой результат из прежнего примера не повторился. Трасса `logs/web-77796ac2dc1140e3a662ee2f52ecdbb1.jsonl`.

## Что доказывает демонстрация

Доказаны подключение локальной модели к IDE, доступ custom agent к MCP, фактическое чтение платформы и зависимость аргументов следующего вызова от результата предыдущего. Три сценария проверены в одной сессии, поэтому последующие запросы могли использовать ранее полученный список ресурсов.

Демонстрация не доказывает правильность всех будущих ответов. В пересказе первого/третьего результата Qwen написала «Справочник по материалов»; фактический path в вызовах был правильным. Итог IDE формирует VS Code, поэтому Python-проверка финального текста здесь не применяется. Для чисел и точных путей сверяйте раскрытый результат инструмента.

Установленный встроенный провайдер Ollama показывает предупреждение deprecated. Он работал в этом прогоне; будущая версия IDE может потребовать отдельного провайдера. Заявленное IDE контекстное окно модели не заменяет настройку 32768 в Python-приложении.
