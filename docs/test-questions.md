## Проверка продолжения беседы

После состава 12Х18Н10Т: «Покажи состав этого сплава ещё раз». После списка бронз: «Покажи состав первой из них». Эти вопросы проверяются в том же диалоге.

Фраза «содержат Cr» означает, что компонент указан в составе базы, а не доказанное ненулевое содержание в каждой партии. Для «где больше хрома» по умолчанию используется верхняя допустимая граница с явным пояснением.
