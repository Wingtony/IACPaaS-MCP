# Сценарий защиты · 8–12 минут

Цель: показать общий MCP API в VS Code и standalone, зависимые вызовы, диагностируемую ошибку и подтверждение записи. Данные платформы и результаты mock называются отдельно. Проверенные результаты собраны в [verification.md](verification.md), фактические промпты и трассы — в [ide-acceptance.md](ide-acceptance.md).

## 0. Подготовка · 1 минута

Из существующей папки проекта запустите `Start-Agent.cmd`. Откройте `http://localhost:8770/`, убедитесь, что выбраны Ollama/qwen-agent и подключение IACPaaS. В окне управления оставьте доступной кнопку остановки. Модель сохраняется в памяти между вопросами; первый запрос после запуска может быть медленнее.

В VS Code откройте эту папку, выберите custom agent **IACPaaS**, модель **qwen-agent:latest**, сервер **iacpaas**. При необходимости вручную подтвердите запуск сервера и передачу результатов. Показывайте `.vscode/mcp.json` и `.github/agents/iacpaas.agent.md`; файл `.env` и хранилища аккаунта не открывайте в демонстрации.

Установка из чистого клона в этот сценарий не входит по указанию пользователя. Работа ведётся в существующем окружении.

## 1. VS Code: найти ресурс и посчитать · 1–2 минуты

> Найди ресурс «Справочник по материалам» и через MCP посчитай в нём вершины и дуги. Покажи фактические вызовы и результат.

Раскройте list_inforesources и count_graph. Ожидаемый путь: `Загрузки/Справочник по материалам`. Зафиксированный результат исходного справочника: **93593 вершины, 93592 дуги, 0 ссылок**. Если сама база изменилась, сравнивайте режимы на одном актуальном снимке, а не подгоняйте числа под отчёт.

Объяснение: первый результат позволяет выбрать точный путь; подсчёт выполняет код по полному графу. Ограничение выдачи не ограничивает вычисление.

## 2. VS Code: прочитать метаданные · 1–2 минуты

> Через MCP найди подключённую «Онтологию базы свойств материалов» и прочитай её метаданные: имя корневой вершины и метапонятие. Не делай полный экспорт и не считай весь граф.

Покажите get_inforesource и глубину экспорта 0. Результат: **Онтология базы свойств материалов**, meta **Язык ИРУО**. В этой же сессии путь может быть взят из предыдущего списка.

## 3. VS Code: поиск → подграф · 1–2 минуты

> В «Справочнике по материалам» найди через query_graph марку 12Х18Н10Т, возьми точный путь из результата и вызови get_subgraph глубиной 1 для этой вершины. Покажи имя, метапонятие и непосредственные разделы. Не придумывай путь вершины.

Раскройте оба вызова. Во втором `path` остаётся путём ИР, а `root` берётся из `matches[].path`: **Сплавы на основе железа/12Х18Н10Т**. Имя — **12Х18Н10Т**, meta — **Материал**, непосредственный раздел — **Элементный состав**. Это три пользовательских сценария непосредственно в IDE, требуемые разделом 7 ТЗ.

## 4. Standalone: тот же подсчёт · 1–2 минуты

В PowerShell из существующей папки проекта:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m iacpaas_mcp.agent --provider ollama --mode adaptive --max-steps 8 "Найди ресурс «Справочник по материалам» и посчитай в нём вершины и дуги."
```

Сравните путь и числа со сценарием 1. Покажите выведенный путь JSONL-трассы: решения, вызовы, аргументы, результаты и сверка. Веб-вариант доступен на localhost и использует тот же Python runtime и серверный API. Проверка по снимку не является доказательством правильности понимания любого вопроса на 100%.

## 5. Ошибка и подтверждение записи · 1–2 минуты

Запустите отдельную демонстрацию на синтетических собственных данных:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m iacpaas_mcp.demo
```

Это прямые MCP-вызовы, **без LLM и без сети**. Демонстрация:

1. Отклоняет depth=6 и показывает диагностический результат.
2. Формирует предпросмотр импорта собственной онтологии и базы.
3. Отказывается от первого предпросмотра, подтверждая нулевое число вызовов изменяющего backend.
4. Ждёт ваше `ДА`. Отказ завершит процесс без записи.
5. После согласия создаёт два учебных графа, считает вершины/дуги и изменяет статус только в новой базе.
6. Повторно читает данные и проверяет новое значение. Отчёт находится в `logs/demo-*/report.json`.

Онтология содержит 4 вершины и 3 дуги. База — 7 вершин и 6 дуг: записи **MCP-сервер** и **Веб-агент**, поля **Статус** и **Число сценариев**. Эти примеры синтетические, не факты об исходных материалах. MockBackend существует только в памяти процесса. Исходная фикстура не изменяется.

### Вариант на настоящей платформе

```powershell
.\.venv\Scripts\python.exe -X utf8 -m iacpaas_mcp.demo --live
```

Этот вариант создаёт **два новых собственных ИР** в папке «Загрузки» с уникальными именами АТЛАС. Перед записью показывает манифест и ждёт отдельное `ДА`. Допускаются только два точных импорта с `clear_if_exists=false` и одно точное изменение в новой базе. Выданные преподавателем ИР исключены из разрешённых путей. Основной сайт остаётся с выключенной записью.

Запускайте live-вариант только когда действительно нужно создать ещё два ресурса; каждый запуск использует новое имя. Ранее созданные ресурсы не удаляются автоматически. Для уже проведённой проверки покажите отчёт и повторное чтение, не создавайте новые копии только ради повтора вывода.

На исходном ПК уже созданы два собственных ИР. Для показа без записи:

```powershell
.\.venv\Scripts\python.exe -X utf8 -m iacpaas_mcp.demo --inspect logs/demo-20261023-011212-0b36b450/manifest.json
```

Живые создание и чтение прошли; update API вернул внутреннюю ошибку `updateVertice`, поэтому статус остался «учебный пример». Это диагностическая ошибка, а не успешное изменение. На mock полный сценарий обновления проходит. Подробности — [live-write-demo.md](live-write-demo.md). При отказе live-update CLI возвращает код 2; не повторяйте импорт ради обхода ошибки.

## 6. Завершение · 30 секунд

Покажите README, схему архитектуры и [успешный CI main](https://github.com/Wingtony/IACPaaS-MCP/actions/runs/39799594616). Скажите, что обычные pytest используют mock/HTTP-заглушки; живые прогоны описаны отдельно. Секреты, реальные экспорты и история остаются локальными.

На собственном компьютере после демонстрации используйте «Остановить всё» или `Stop-Web.cmd`: это завершает Web и выгружает Qwen. Если продолжаете работать, приложение можно оставить запущенным.
