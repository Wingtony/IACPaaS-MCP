# Изменения

## 2026-11-16 · Проверка одногруппниками: дерево и повторы

- Добавлен `get_children` (17-й MCP-инструмент): страницы непосредственных детей, точные пути, контроль снимка. Web раскрывает дерево по требованию; широкий подграф возвращает понятный код/413 вместо общего 502. Запрос конкретной ветки структуры больше не подменяется корнем справочника.
- Успешное одинаковое чтение повторно не исполняется. Отдельный предел попыток без новых данных останавливает циклы и сохраняет проверенные частичные результаты; диагностика различает шаги, вывод, ошибку/таймаут модели и thinking без решения. Общий бюджет задаётся окружением/CLI (1–60), предел без прогресса — отдельно.
- Запросы «самый прочный»/«лучший для отрасли» требуют измеряемых критериев; состав не объявляется доказательством прочности/пригодности. Явно запрошенное сравнение по составу сопровождается оговоркой.
- Уточнены смысл Host whitelist, авторизация посетителей и границы сверки по снимкам. Добавлены регрессии циклов, широких деревьев, страниц, подмены данных и запросов структуры; живая навигация справочника проверена только чтением, без запуска LLM.

## 2026-11-12 · Составные вопросы и память объекта

- Общие вопросы и связи больше не сводятся к двухстрочной карточке: добавлен проверяемый `overview` по выбранным базам, атрибуты, вещества/материалы/другие связи, основания, полные количества и страницы. Нулевые связи сообщаются явно.
- Перед завершением проверяются распознанные части вопроса; неполный ответ не становится полным от одной оценки модели. В UI отдельно показаны сверка данных и выполнение частей, справка о возможностях не требует уточнения объекта.
- Однозначные уточнения по известному объекту и страницы выполняют новый MCP-запрос без повторного угадывания объекта моделью. Новый явно названный объект не подменяется предыдущим; узкий вопрос о веществах не повторяет карточку/материалы.
- Обновлены инструкции IDE и банк примеров (42). Проверены реальная история Fe, свежий контекстный запрос и отказ одной базы; исходные ресурсы и диалоги не изменялись, платные API не вызывались.

## 2026-11-12 · Привязка фрагментов без переписывания цитат

- Устранён сбой «цитаты нет в ответе»: проверяющий выбирает ID готового фрагмента, а точный текст восстанавливает приложение. Числа, отрицания, Markdown и Unicode не нормализуются и не угадываются.
- На реальной локальной Qwen обнаружено добавление лишнего `/data` к ссылкам. Вместо составления путей модель теперь выбирает готовый ID факта из каталога скаляров/строк; допустимые ID ограничены JSON Schema. Значение и путь получает код.
- Неизвестный ID отмечается ошибкой одного пункта и не отменяет проверку остальных утверждений. Сохранена защита от ссылок на сам ответ. Web сообщает версию проверки 3 и не позволяет новому UI запускать старый backend.

## 2026-11-11 · Исправление смысловой проверки

- Исправлена причина ложного «1 из 11»: сравнение пересказанного моделью значения с буквальным JSON смешивало ошибку формата с отсутствием данных. Теперь модель выбирает ссылку, а значение извлекает код после повторной проверки исходного результата.
- Исключены ссылки на сам проверяемый ответ и служебные поля. Ошибки ссылок отделены от отсутствия данных и противоречий, в том числе для отрицательных вердиктов. Старые отчёты явно помечены устаревшими.
- Ограничены объём ответа модели (1536 токенов) и выборка (до 8 утверждений), добавлены таймер, отмена и общий предел 120 секунд. Неполные результаты не сохраняются. Шаги/снимки сохранённого пользовательского ответа проверены без запуска LLM.

## 2026-11-11 · Docker, отдельная Ollama и предметные сценарии

- Основной запуск перенесён в Docker Compose: Web/агент/MCP на сервере, Ollama отдельно на ПК или облачный API. Адрес Ollama сохраняется в выборе моделей, проверяется из контейнера; доступны имена установленных моделей. Остановка контейнера не выгружает внешнюю LLM.
- Сетевой доступ защищён паролем, точным списком разрешённых Host и существующими Origin/CSRF-проверками. Данные и ключ Unix-хранилища сохраняются в volume; настройки входа не подменяют deployment-пароль/адреса при рестарте.
- Добавлены условия состава И/ИЛИ, наличие/отсутствие, строгие сравнения, страницы с защитой от изменения данных; расширен банк вопросов до 39.
- Сервер строит JSON своих ресурсов по ограниченной схеме онтологии, проверяет типы/обязательность, поддерживает создание папок и удаление своих ИР. Запись в выданные базы запрещена сервером; любые записи требуют MCP-подтверждения человека.
- Индекс сверяет даты, поддерживает явную синхронизацию и честно маркирует резервные снимки. Добавлена отдельная LLM-проверка утверждений с точной сверкой цитат и JSON Pointer; гарантия абсолютной истинности не заявляется.
- Проверена ветка одногруппника `dev_unix_support`; переносимые команды и shell-скрипты доработаны вместо слияния незавершённых обёрток. В CI добавлены Windows/Linux/macOS и сборка/health-check Docker.
- Девять новых сценариев чтения на подключённой БД прошли повторную сверку со снимками. Живых записей и платных API-вызовов при доработке не было; ограничения конструктора и развёртывания описаны в документации.

## 2026-10-23 · Комплект сдачи и собственные графы

- Актуализирован отчёт проверок; ранние заметки отделены в архив. Подготовлен сценарий защиты с тремя сценариями IDE, повтором standalone, ошибкой запроса и подтверждением записи.
- Добавлен отдельный MCP demo: mock без сети/LLM, live только после согласия на точный манифест, inspect только для чтения уже созданного. Допустимы только два новых собственных графа и одно точное изменение; очистка и изменение исходных баз исключены.
- С согласия пользователя реально созданы собственная онтология проектов и база из двух записей. Повторное чтение подтвердило 4/3 и 7/6 вершин/дуг.
- Живой update API вернул внутреннюю ошибку updateVertice. Добавлены невозобновляемая диагностика, честный частичный результат демонстрации и тесты; успех обновления не заявляется.
- Подтверждён успешный CI после слияния main. Установка из чистого клона исключена из проверки по указанию пользователя.

## 2026-10-23 · Адаптивный MCP runtime

- Исправлена регрессия Web на зависимом query_graph → get_subgraph: сохранены решения модели и аргументы вызовов в контексте, разделены path ИР и root вершины, добавлена конкретная диагностика и таблицы по проверенным результатам. Точный вопрос пользователя завершился за 69,7 с вместо обрыва на 211,8 с.
- Основной агент теперь выбирает инструменты по их реальным схемам, использует результаты предыдущих шагов, оценивает достаточность и получает диагностические ошибки для перепланирования. Добавлены режимы CLI `adaptive`, `knowledge`, `raw` и ограничение шагов.
- Сохранена повторная проверка фактов и расчётов по снимкам; неполный поиск и уточнение не получают статус полной верификации. Подтверждение записи остаётся в хосте, вне контекста модели.
- Добавлены предметные схемы выходов и строгая проверка успешных результатов всех MCP-инструментов, структурированные ошибки с рекомендацией следующего действия.
- Исправлена работа с истёкшим сохранённым JWT IACPaaS: обновление для того же аккаунта, безопасный повтор только чтения, без повторения мутаций.
- Контекст учитывает схемы и наблюдения цикла; большие результаты доступны по ID и JSON Pointer без потери исходных данных.
- Добавлены проверки адаптивного цикла для локального и пяти облачных адаптеров, обновления JWT и политик. Проверены реальные Qwen, MCP stdio и подключение VS Code; детали и ограничения в документации.

## 2026-10-22 · Выбор облачных моделей

- Добавлены OpenAI, Anthropic Claude, Google Gemini, DeepSeek и OpenRouter наряду с локальной Ollama. API ID можно выбрать из примеров или ввести вручную.
- В Web добавлено окно «Модели и API»: выбор провайдера, сохранение/замена/удаление ключей, явная проверка API и описание передаваемых данных.
- Ключи хранятся отдельно через Windows DPAPI, не возвращаются клиенту и не попадают в трассы. Поддержаны ключи из переменных окружения.
- Облачный план использует прежние MCP, расчёты и повторную верификацию ответа. Переход на облако при управляемом запуске освобождает локальную модель; облачный запуск не требует Ollama.
- В CLI добавлены `--provider` и `--model`. В истории отображается использованная модель.
- Добавлены контрактные и интеграционные тесты с HTTP-заглушками. Реальные платные API-вызовы не проверялись без пользовательских ключей.
