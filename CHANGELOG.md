# Изменения

## 2026-10-23 · Адаптивный MCP runtime

- Исправлена регрессия Web на зависимом query_graph → get_subgraph: сохранены решения модели и аргументы вызовов в контексте, разделены path ИР и root вершины, добавлена конкретная диагностика и таблицы по проверенным результатам. Точный вопрос пользователя завершился за 69,7 с вместо обрыва на 211,8 с.
- Основной агент теперь выбирает инструменты по их реальным схемам, использует результаты предыдущих шагов, оценивает достаточность и получает диагностические ошибки для перепланирования. Добавлены режимы CLI `adaptive`, `knowledge`, `raw` и ограничение шагов.
- Сохранена повторная проверка фактов и расчётов по снимкам; неполный поиск и уточнение не получают статус полной верификации. Подтверждение записи остаётся в хосте, вне контекста модели.
- Добавлены предметные схемы выходов и строгая проверка успешных результатов всех MCP-инструментов, структурированные ошибки с рекомендацией следующего действия.
- Исправлена работа с истёкшим сохранённым JWT IACPaaS: обновление для того же аккаунта, безопасный повтор только чтения, без повторения мутаций.
- Контекст учитывает схемы и наблюдения цикла; большие результаты доступны по ID и JSON Pointer без потери исходных данных.
- Добавлены проверки адаптивного цикла для локального и пяти облачных адаптеров, обновления JWT и политик. Проверены реальные Qwen, MCP stdio и подключение VS Code; детали и ограничения в документации.

## 2026-10-22 · Выбор облачных моделей

- Добавлены OpenAI, Anthropic Claude, Google Gemini, DeepSeek и OpenRouter наряду с локальной Ollama. API ID можно выбрать из примеров или ввести вручную.
- В Web добавлено окно «Модели и API»: выбор провайдера, сохранение/замена/удаление ключей, явная проверка API и описание передаваемых данных.
- Ключи хранятся отдельно через Windows DPAPI, не возвращаются клиенту и не попадают в трассы. Поддержаны ключи из переменных окружения.
- Облачный план использует прежние MCP, расчёты и повторную верификацию ответа. Переход на облако при управляемом запуске освобождает локальную модель; облачный запуск не требует Ollama.
- В CLI добавлены `--provider` и `--model`. В истории отображается использованная модель.
- Добавлены контрактные и интеграционные тесты с HTTP-заглушками. Реальные платные API-вызовы не проверялись без пользовательских ключей.
